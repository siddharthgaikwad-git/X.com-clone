# 𝕏 (Twitter) Clone

A responsive, pixel-perfect social media web interface inspired by 𝕏, built using modern Tailwind CSS. Created to master multi-column responsive grid layouts, sticky navigation, and modern dark mode UI styling.

🔗 **Live Demo:** [https://x-com-clone.pages.dev/](https://x-com-clone.pages.dev/)

---


## 🛠️ Tech Stack

- **Markup:** HTML5
- **Styling:** Tailwind CSS (Custom compiled via Tailwind CLI)
- **Icons:** Google Material Symbols & Inline SVGs
- **Deployment:** Cloudflare Pages
